# Gemini 技能設定：週報 Skill

在 Gemini 的 Customize → Skills 中加入或建立技能時，依欄位貼上以下內容。
（實際欄位名稱依錄製當下的畫面為準。）

## 名稱
週報 Skill

## 說明
把每週的待辦表、工作紀錄與數據 CSV 整理成固定四段格式的一頁週報。

## 指示
# 週報 Skill

把每週的待辦、工作紀錄與數據，整理成固定四段格式的一頁週報。

## 何時使用
使用者要求製作週報、提到「週報 Skill」，或提供一週的待辦、工作紀錄與數據並要求整理成報告時。

## 必要資料
- 待辦表或信件整理結果
- 工作紀錄
- 本週數據 CSV（任務、狀態、金額）

缺少任何一份時，先告知使用者缺哪一份，不要自行補資料。

## 步驟與規則
1. 先讀資料並確認資料期間。
2. 使用固定四段格式。
3. 計算三項指標：完成數、未完成數、金額合計。
4. 未知資訊標「待確認」，不猜測、不補寫。
5. 交件前回查來源，數字與期限對回原始資料。

## 計算口徑
完成數＝狀態為「完成」的列數；未完成數＝其餘列數；金額＝金額欄加總，空白不計入並標「待確認」。

## 輸出格式（固定四段，一頁以內）
### 一、本週結論
### 二、關鍵數字
### 三、待確認事項
### 四、下一步

- 「本週結論」用一到兩句說明本週狀況與最近的期限。
- 「關鍵數字」列出完成數、未完成數、金額合計。
- 「待確認事項」列出所有原始資料沒有交代的資訊（例如沒有負責人、空白金額），不得猜測。
- 「下一步」列出有期限的後續工作，期限以最新的更正信為準。
- 最後一行附上「資料來源」與「資料期間」。

## 限制
本 Skill 只保存工作做法，不寄信、不刪除、不連線外部服務，也不會自動定時執行。
